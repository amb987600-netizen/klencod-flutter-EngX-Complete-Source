# EngX — صيانة الأجهزة الطبية

مشروع واحد للويب وأندرويد وiPhone: أجهزة وصيانة ومخزون ووقائية وتقويم وتقارير، مع حفظ محلي واستيراد Excel ونسخ احتياطي مشفر. أُضيفت Widgets أصلية للمنصتين ومحادثة اختيارية للفريق بأرقام داخلية بدل أرقام الموبايل.

**مهم:** هذه حزمة المصدر ومشروعَي Android وXcode، وليست APK أو IPA موقّعين. نسخة الويب مبنية في `dist/`. تطبيقات الهاتف والودجت تحتاج بناءً واختبارًا على الأجهزة؛ لم يتم تشغيل Xcode أو اختبار هاتف حقيقي في هذه البيئة. التطبيق أداة تنظيم، وليس شهادة سلامة أو اعتمادًا طبيًا.

## ابدأ بأبسط طريقة

ثبّت Node.js 22 LTS، ثم شغّل `START-ENGX.bat` على ويندوز أو `./start-engx.sh` على لينكس/ماك. هذا يفتح النسخة المبنية على `http://localhost:5173`، دون حساب أو سحابة. اترك نافذة التشغيل مفتوحة. لا تفتح `dist/index.html` بالنقر المباشر؛ التخزين والتشفير يحتاجان عنوانًا صحيحًا.

للتطوير والاختبار:

```bash
npm ci
npm run dev
npm test
npm run build
```

## الاستخدام اليومي السريع

أضف جهازًا باسمه وكوده فقط. الشركة والموديل والسيريال والموقع والصورة والملاحظات اختيارية. الحالة غير المحددة لا تعني أن الجهاز يعمل.

من «أمر جديد» اختر الجهاز واكتب وصف العطل. تُحفظ المسودة تلقائيًا؛ وقت الاكتشاف يُسجّل بتوقيت الموبايل ويمكن تعديله إذا اكتُشف العطل سابقًا. وقت إنشاء السجل الأصلي لا يتغير، والتعديل له أثر في سجل النشاط. افتح التفاصيل لاحقًا للفحص والقطع والمرفقات. قائمة السلامة ونتائج الاختبار واعتماد المالك/المدير مطلوبة عند **الإغلاق النهائي فقط**، لا عند تسجيل البلاغ.

## Android

تحتاج Android Studio وJDK 21 وAndroid SDK:

```bash
npm ci
npm run android:sync
npm run android:open
```

ابنِ APK تجريبيًا من Android Studio، أو اضبط مفاتيحك لإصدار موقّع. لا توجد مفاتيح توقيع في الحزمة.

## iPhone وiPad

تحتاج Mac وXcode 16 أو أحدث وiOS 15 أو أحدث:

```bash
npm ci
npm run ios:sync
npm run ios:open
```

اختر Development Team وBundle IDs المناسبين لك في Xcode. الودجت مضافة كهدف مستقل باسم `EngXWidget`. فعّل App Groups المشتركة للتطبيق والودجت كما في [دليل Widget الآيفون](docs/IOS-WIDGET.ar.md). إعداد App Groups وتوزيع التطبيق قد يتطلبان عضوية Apple مناسبة. لا تتضمن الحزمة ملف IPA أو نشرًا في App Store.

نسخة الويب يمكن استضافتها عبر HTTPS وفتحها من Safari وإضافتها للشاشة الرئيسية. **إضافة موقع للصفحة الرئيسية ليست WidgetKit**؛ الودجت تتطلب النسخة الأصلية الموقّعة.

## الودجت وQR

بعد تثبيت النسخة الأصلية، فعّل ملخص الودجت من «الإعدادات ← الخصوصية»، ثم أضف EngX من قائمة Widgets في الهاتف. تعرض أعداد الأوامر المفتوحة والوقائية المستحقة وأقرب المواعيد، مع اختصارات لأمر جديد وقراءة QR. تُحدّث نسخة الملخص عند فتح التطبيق/تغيير البيانات؛ لا توجد مزامنة مضمونة أثناء إغلاقه، ويظهر وقت آخر تحديث. إيقاف الخيار يزيل أسماء الأجهزة من الملخص.

قراءة QR تتم من صورة تلتقطها أو تختارها، أو بإدخال الكود. تُحلّل الصورة محليًا ولا تُرفع، وتفتح جهازًا موجودًا في مساحة العمل الحالية فقط. يدعم التطبيق أيضًا روابط `engx://device/ID` و`engx://new-order` و`engx://scan`.

## Excel والنسخ الاحتياطي

الاستيراد يدعم `.xlsx` و`.xls` و`.csv`، من الورقة الأولى: معاينة ثم ربط أعمدة ثم تحقق وتأكيد. يوجد مثال داخل `examples/`. التراجع عن آخر دفعة يحذف فقط السجلات غير المعدلة وغير المرتبطة، ولا يمحو عملًا أُضيف بعدها. حدود الاستيراد 20MB و10,000 صف؛ حد المرفق 10MB.

من النسخ الاحتياطي أنشئ ملفًا مشفرًا بكلمة مرور 10 أحرف على الأقل واحفظه **خارج الهاتف**. يشمل السجلات وسجل النشاط والمرفقات والرسائل والملفات التي حُفظت من المحادثة. يوجد اختبار استرجاع معزول لا يغيّر بياناتك. لاستعادة هاتف جديد اختر الملف وكلمته وراجع المعاينة؛ لا تعتمد على تسجيل Google وحده. لا توجد إعادة تعيين لكلمة مرور النسخة.

## السحابة والفريق والمحادثة — اختيارية

يحتاج التواصل بين أجهزة مختلفة خادمًا منشورًا عبر HTTPS، وليس مجرد تشغيل الواجهة على كل هاتف:

```bash
cd server
npm ci
cp .env.example .env
# اضبط JWT_SECRET عشوائيًا قويًا وCORS_ORIGIN حسب عنوانك
npm test
npm start
```

الخادم Express وSQLite. الواجهة المحلية Dexie/IndexedDB؛ لا توجد قاعدة سحابية مستضافة ومضبوطة مسبقًا. أدخل عنوان الخادم من الإعدادات وأنشئ الحساب ثم فعّل السحابة. لا تُرسل بيانات المستشفى إلى الخارج دون تصريحها. انسخ قاعدة الخادم وملفاته دوريًا حسب سياستك.

المحادثة مجموعة لكل مساحة عمل، وليست مكالمات أو رسائل SMS أو محادثات خاصة فردية. لكل حساب رقم داخلي فريد من الخادم. الجديد يظهر بتحديث تلقائي أثناء فتح المحادثة والاتصال؛ دون إنترنت ترى فقط ما استلمته وحفظته. رفع الملف يحتاج اختيارك ثم إرسالًا، وتنزيل المرفقات ليس تلقائيًا. لا توجد إشعارات دفع أو استلام جديد مضمون بعد إغلاق التطبيق. الاتصال يحتاج HTTPS، **ولا توجد حماية تشفير طرف لطرف مماثلة لواتساب**.

الأدوار: مالك، مدير، فني، ومشاهد للقراءة. ضوابط المساحة والإيقاف والصلاحيات تُفحص على الخادم. إيقاف عضو دون اتصال لا يمكن أن يصل للهاتف فورًا؛ تُمسح نسخته المحلية عند أول رد من الخادم بإيقاف الوصول.

## حدود صريحة

- Google Sign-In منفذ للويب عند إعداد Client ID. تسجيل Google داخل WebView لأندرويد/iPhone ليس تكاملًا أصليًا جاهزًا؛ استخدم البريد وكلمة المرور للنسخة الأصلية. لا يوجد ربط Drive/Gmail/Contacts أو Google Sheets؛ صدّر Excel وارفعه يدويًا.
- التخزين المحلي نفسه غير مشفر على مستوى التطبيق؛ النسخ الاحتياطية فقط AES-256-GCM مع PBKDF2-SHA256 و310000 دورة. استخدم قفل الجهاز وسياسة المؤسسة.
- شات المساعد يدعم أوامر محلية محددة بدون نموذج، ونموذج LiteRT-LM اختياريًا على الأجهزة الأصلية، وAPI خاص بالمستخدم اختياريًا. لا يوجد استخراج محتوى PDF تلقائي.
- التعارضات تُرفض للمراجعة بدل دمج صامت. المرفقات مضمنة كبيانات في الطلبات، وليست نظام رفع خلفي منفصل للملفات الكبيرة.
- الإنجليزية تغطي عناوين التنقل الرئيسية، وليست ترجمة كاملة لكل شاشة. المجال المفعّل هو الأجهزة الطبية فقط.
- سجل النشاط يسجل العمليات والتنقل والبحث والتغييرات والاستيراد والنسخ والدخول والفريق؛ لا يسجل كل حرف أو كل لمسة. لا يمكن تعديله من الواجهة؛ امتلاك الجهاز/الخادم لا يعادل سجلًا جنائيًا غير قابل للعبث.
- لا تضع بيانات مرضى أو قيم سلامة مخمّنة في أي خانة أو رسالة أو ملف. إغلاق أمر صيانة لا يثبت وحده السلامة السريرية.

راجع [دليل الاستخدام](docs/USER-GUIDE.ar.md) و[الأمان والخصوصية](docs/SECURITY.ar.md) و[قائمة الوظائف](docs/FEATURES.ar.md).

## شات المساعد: محلي مجاني + API اختياري

من «شات المساعد» اكتب مثلًا `أضف جهاز: جهاز تجربة | كود: TEST-020` أو `ابحث عن TEST-020` أو `جهز تقرير`. تظهر معاينة قبل إنشاء السجلات، والتطبيق يعيد فحص حسابك ومساحتك وصلاحياتك قبل التنفيذ. هذه صياغات محددة تعمل دون إنترنت أو نموذج. المحادثة الخاصة مؤقتة للجلسة، لكن السجلات المنفذة وأثرها محفوظان.

لفهم أكثر مرونة، افتح المساعد الاختياري: **المحلي هو الافتراضي**. التكامل الأصلي يستخدم Gemma 4 E2B وLiteRT-LM. ملف النموذج نحو 2.58 GB، يُنزَّل فقط بموافقة صريحة ويُفحص حجمه وبصمته، ولا يُضمَّن في ZIP أو النسخة الاحتياطية. يحتاج جهازًا متوافقًا ووقتًا ومساحة، ولا توجد رسوم API لكل رسالة محلية. Swift والويب في LiteRT-LM موصوفان رسميًا كـ Early Preview؛ التشغيل المحلي في نسخة الويب الحالية غير مفعّل، ولا يتم التحويل إلى API تلقائيًا. راجع [تفاصيل أندرويد](docs/ANDROID-LOCAL-AI.ar.md) و[تفاصيل iPhone](docs/IOS-LOCAL-AI.ar.md).

وضع API يقبل عنوان HTTPS واسم نموذج ومفتاحًا بصيغة OpenAI-compatible فقط. يُحفظ المفتاح في Android Keystore/Apple Keychain، ولا يُعاد للواجهة أو يدخل السجل أو النسخ. في الويب يكون مؤقتًا في ذاكرة الشاشة فقط، ويتطلب CORS من المزود. اختبار الاتصال يرسل طلبًا صغيرًا ثابتًا وقد يحاسبه مزودك. تشغيل API يحتاج اختيار الوضع وموافقة الإرسال والضغط على تشغيل، ولا تُضمَّن رسائل أو ملفات إلا باختيارك. الرسوم والشروط عند المزود وليست مجانية بالضرورة.

المساعد يقترح فقط الأفعال المدعومة، وليس تحكمًا غير محدود: إضافة جهاز، مسودة أمر صيانة، بحث وتجهيز تقرير. لا ينفذ حذفًا أو إغلاقًا نهائيًا أو تغيير صلاحيات عبر النص؛ استخدم الشاشة المختصة وتأكيدها وقائمة تحققها واعتمادها. الرد أو اقتراح JSON لا ينفذ كودًا ولا يُنشر للفريق تلقائيًا. المرفقات التي يمكن إضافتها كسياق يدويًا TXT/CSV فقط؛ لا تحليل PDF تلقائي.

## الأكواد والترتيب والمستندات

كل سجل له كود ثابت يحتوي نوعه ومعرّفه الكامل بترميز Base32، بما فيه الصيانة والبيع والشراء والتقارير. لا يتغير بعد المزامنة. يستخدم معرفات عشوائية طويلة لا عدادًا محليًا قصيرًا حتى لا تتصادم أجهزة تعمل دون اتصال؛ الخادم يرفض تغيير الكود أو تكراره، حتى بعد الحذف الناعم. عمود «م» هو **ترتيب العرض** ويمكن عرضه تصاعديًا أو تنازليًا، وليس رقم فاتورة عالميًا متتابعًا. الترقيم العالمي المتتابع بلا فجوات غير مضمون عند إنشاء سجلات أوفلاين من أجهزة متعددة.

البحث العلوي يشمل جميع السجلات المحفوظة محليًا بالاسم والكود والحقول النصية، مع النتائج وأكوادها. شاشة «بيع وشراء ومستندات» تنشئ سجلات داخلية بعملة وبنود يحددها المستخدم، دون دفع حقيقي أو فواتير ضريبية أو محاسبة معتمدة. التقرير يُحفظ كلقطة مرقمة قبل التصدير، ويظل كوده ثابتًا عند إعادة طباعته. المشاهد يقرأ المحفوظ ولا ينشئ تقارير جديدة.
