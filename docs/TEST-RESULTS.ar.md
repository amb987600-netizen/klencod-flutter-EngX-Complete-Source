# ما تم اختباره في EngX

نجحت 28 حالة اختبار محلية عبر Vitest و9 حالات HTTP للخادم عبر Node Test. نجح فحص TypeScript وتجميع نسخة الويب بواسطة Vite، ثم نسخ الأصول وتحديث إضافات Capacitor في مشروعي Android وiOS.

تغطي الاختبارات الحفظ دون اتصال، الصلاحيات المحلية، سلامة إغلاق الصيانة، خصم المخزون الذري وعدم تكراره، تحقق Excel والتراجع، تشفير النسخ وكشف التغيير وكلمة المرور الخاطئة، الاستعادة، أكواد السجلات وثباتها، تحليل أوامر المساعد ورفض أفعال غير مسموحة، عزل مساحات العمل، الدعوات والإيقاف، وأذونات المحادثة وفصل بيانات المرفق عن قائمة الرسائل.

جُرّبت الواجهة في المتصفح ببيانات وهمية: إضافة جهاز، فتح ملفه وQR، حفظ مسودة صيانة سريعة مع الوقت التلقائي، ثم طلب إضافة جهاز من شات المساعد ومعاينته وتأكيده. ظهر كود الجهاز الناتج بعد التنفيذ. أُصلح اختلاف همزة «أضف» المكتشف في التجربة وأُضيف له اختبار رجوع.

## ما لم يُختبر

- لم تُبنَ نسخة APK أو IPA موقعة، ولم يُختبر هاتف فعلي أو إشعاراته أو الودجت أو الطباعة الأصلية.
- لا يتوفر Xcode في Linux. أدوات Android الحالية لا تكفي لاعتماد بناء أصلي ناجح؛ يلزم Android Studio وSDK وJDK المناسبون على جهاز البناء.
- لم يُنزَّل نموذج Gemma البالغ نحو 2.58 GB ولم تُجرَ عليه إجابة حقيقية. دمج LiteRT-LM مصدر أصلي يحتاج اختبار جهاز متوافق. Swift موصوف رسميًا Early Preview.
- لم يُستخدم مفتاح API حقيقي أو مزود مدفوع للاختبار. اختبار الاتصال المدمج يعمل فقط عندما يضبط المستخدم مزوده ويضغطه بنفسه، وقد يفرض المزود رسومًا.
- لم يتم نشر خادم إنتاج أو إجراء تدقيق اختراق أو اعتماد طبي/تنظيمي. الاختبارات ليست بديلًا عن اختبار القبول وسياسة المؤسسة.
